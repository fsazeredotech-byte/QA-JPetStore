# 📸 Evidências

Prints da execução dos casos de teste. **Como capturar e proteger:** ver [`PROTOCOLO-EXECUCAO.md`](../PROTOCOLO-EXECUCAO.md), seção 3.

**Padrão de nome (a partir da versão 3):**
```
CASO_DATA_HORA_TENTATIVA_ETAPA.png (ou .jpg)   ex.: PS-TC-002c_20261103_142501_T01_02-depois-salvar.png
```
Etapas: `01-antes-salvar` · `02-depois-salvar` · `03-antes-login` · `04-depois-login` · `05-my-account`

**Arquivos anteriores ao protocolo** (nomes simples, sem data/hora) foram mantidos como estavam. As limitações de cada um estão descritas no caso de teste ou no bug correspondente.

⚠️ Senhas e dados pessoais são cobertos com **tarja opaca** antes da publicação — este repositório é público.
