# 🐞 BUG-003 — Campos de senha do cadastro exibem a senha em texto visível

| Campo | Descrição |
|---|---|
| **ID** | BUG-003 |
| **Status** | 🔴 Aberto — observado em 03/11/2026 |
| **Título** | Os campos "New password" e "Repeat password" do cadastro exibem a senha em texto claro |
| **Ambiente** | A01: navegador integrado do app Claude Desktop 4.4212.0 (Chromium 152.0.7977.167) · Windows 10 64-bit · https://jpetstore.mate.academy |
| **Caso de teste relacionado** | Encontrado durante a execução do PS-TC-002 (observação exploratória) |
| **Pré-condição** | Usuário não logado. |
| **Passos para reproduzir** | 1. Abrir https://jpetstore.mate.academy/actions/Catalog.action<br>2. Clicar em **Sign In** → **Register Now!**<br>3. Digitar qualquer valor em **New password** e **Repeat password** |
| **Resultado esperado** | Os caracteres digitados aparecem mascarados (•••). |
| **Resultado atual** | A senha aparece legível na tela. Inspecionando a página (DevTools), os dois campos são:<br>`<input name="password" type="text">`<br>`<input name="repeatedPassword" type="text">`<br>em vez de `type="password"`.<br>🔍 **Comparação:** na tela de **login** (Sign In), o campo Password **é mascarado** (•••), como mostra o [print 03 do PS-TC-002c](../evidencias/PS-TC-002c_20261103_125930_T02_03-antes-login.jpg). O problema é específico da tela de cadastro. |
| **Frequência** | Sempre: o tipo do campo está definido no próprio código da página. |
| **Severidade** | 🟡 **Minor**: o cadastro continua funcionando, mas qualquer pessoa olhando a tela consegue ler a senha (*shoulder surfing*), e navegadores e gerenciadores de senha não tratam o valor como sensível. *(Major também é defensável por envolver credenciais.)* |
| **Prioridade** | 🟠 **Alta**: é um risco de segurança que afeta todos os cadastros. |
| **Evidência** | [`evidencias/BUG-003-senha-visivel.jpg`](../evidencias/BUG-003-senha-visivel.jpg) (os campos de senha estavam legíveis na captura original; na imagem publicada foram cobertos com tarja preta) |
| **Reportado por** | Fabricio S Azeredo · 03/11/2026 |

## 🔐 Observação de segurança
Um campo de senha deve usar `type="password"`. Assim, o valor fica mascarado na tela e os navegadores e gerenciadores de senha tratam o dado como sensível.
