# 🐞 Modelo de bug report

> Copie este arquivo como `BUG-001.md`, `BUG-002.md` etc. **somente quando encontrar um defeito real** na execução.

| Campo | Descrição |
|---|---|
| **ID** | BUG-000 |
| **Título** | _[O que acontece] + [onde] — ex.: "Cadastro aceita User ID com caractere especial"_ |
| **Ambiente** | jpetstore.mate.academy · Navegador e versão · Sistema operacional |
| **Caso de teste relacionado** | PS-TC-00X → PS-REQ-00X |
| **Pré-condição** | |
| **Passos para reproduzir** | 1.<br>2.<br>3. |
| **Dado de teste** | |
| **Resultado esperado** | |
| **Resultado atual** | |
| **Severidade** | Blocker / Critical / Major / Minor / Trivial |
| **Prioridade** | Crítica / Alta / Média / Baixa |
| **Evidências** | `evidencias/BUG-000.png` |
| **Data / Reportado por** | |

💡 **Severidade** = impacto técnico do defeito. **Prioridade** = urgência da correção para o negócio.
