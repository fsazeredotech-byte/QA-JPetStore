# 🐞 BUG-002 — Cadastro aceita User ID com caractere especial

| Campo | Descrição |
|---|---|
| **ID** | BUG-002 |
| **Status** | 🔴 Aberto — observado em 03/11/2026 |
| **Título** | O campo User ID aceita caracteres especiais (`!` e `@`), e a conta é criada |
| **Ambiente** | A01: navegador integrado do app Claude Desktop 4.4212.0 (Chromium 152.0.7977.167) · Windows 10 64-bit · https://jpetstore.mate.academy |
| **Caso de teste relacionado** | [PS-TC-002](../casos-de-teste/casos-de-teste-cadastro.md#ps-tc-002--não-aceita-caracteres-especiais), variações 002-a e 002-b → PS-REQ-002 |
| **Pré-condição** | Usuário não logado. O User ID usado ainda não existe. |
| **Passos para reproduzir** | 1. Abrir https://jpetstore.mate.academy/actions/Catalog.action<br>2. Clicar em **Sign In** → **Register Now!**<br>3. Em **User ID**, digitar `User!123`<br>4. Preencher a senha e os demais campos com dados válidos<br>5. Clicar em **Save Account Information**<br>6. Clicar em **Sign In** e entrar com `User!123` e a senha definida<br>7. Abrir **My Account** |
| **Resultado esperado** | No passo 5, uma mensagem de erro informa que o User ID deve conter apenas letras e números (PS-REQ-002), e a conta não é criada. |
| **Resultado atual** | Passo 5: nenhuma mensagem de erro; o sistema volta à página principal. Passo 6: o login funciona ("Welcome Teste!"). Passo 7: a página **My Account** mostra **User ID: User!123**. A conta foi criada com o caractere especial. |
| **Frequência** | Observado em **2/2** variações executadas: `User!123` (002-a) e `User@123` (002-b). A variação com `#` (002-c) ainda não foi executada. |
| **Severidade** | 🟠 **Major**: viola diretamente o PS-REQ-002 e grava no sistema contas que a regra proíbe. Corrigir depois exigirá tratar as contas inválidas já existentes. *(Severidade média também é defensável com a evidência atual; mantida como Major por esse impacto de dados.)* |
| **Prioridade** | 🟠 **Alta**: é uma regra explícita do requisito, observada com dois símbolos diferentes. |
| **Evidência** | [`evidencias/BUG-002-conta-criada.jpg`](../evidencias/BUG-002-conta-criada.jpg) (My Account com o User ID `User!123`) · [`evidencias/PS-TC-002b-apos-salvar.jpg`](../evidencias/PS-TC-002b-apos-salvar.jpg) (página principal depois de salvar `User@123`; sozinha, não mostra o ID usado) |
